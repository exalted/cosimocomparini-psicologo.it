# cosimocomparini-psicologo.it

Static site, built with Jekyll + Tailwind, deployed to GitHub Pages via Actions.

## Local development

```
./script/start
```

That's it. The script auto-loads the pinned Node (via nvm, from `.nvmrc`) and Ruby (via rbenv, from `.ruby-version`), then runs Jekyll, PostCSS, and Prettier in watch mode with livereload.
